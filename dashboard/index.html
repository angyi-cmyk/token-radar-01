How the ranking scores a protocol

Every row on the board is priced by one function of the snapshot, and nothing else. It takes the protocol’s total value locked, multiplies it by the sector multiple — the median market-cap-to-TVL ratio of live-token protocols in the same category, shrunk toward the global median when the category has few live comparables — then adjusts for seven-day growth, for how long the protocol has run with no token, and for how many chains it spans. The board recomputes each row in the browser and checks the number against the data file, so a stale figure would show up immediately.

  1. TVL is the anchor. A protocol holding more value would, all else equal, support a larger token.
  2. Growth moves the price. Seven-day TVL change is clamped and counted at half weight, so a hot week lifts a row without letting a spike dominate.
  3. Age is a discount. A protocol that has run for years with no token is scored as less likely to launch one soon than a young one.
  4. More chains, more reach. Each extra chain adds a small multiplier, capped at ten extra chains.

Implied value is a model, not a price and not a promise. A protocol on this board may never issue a token, and a token that does launch can trade far from any model. The farm plan on each row is a starting point for research, not financial advice.

Wrapped, staked and bridged products are kept off the board: their token already trades.
